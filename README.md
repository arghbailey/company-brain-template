# Company Brain (template)

This is a generic, company-agnostic template. It has no company data — see `START-HERE.md`.

To instantiate it for a real company: copy this repo to a **new, separate, private** repo
(don't push company data back here), fill in `config/company.yml` from
`config/company.example.yml`, and populate `wiki/` from real, inspectable sources.
